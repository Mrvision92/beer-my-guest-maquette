Guide de reconstruction dans Wix Harmony

Pour : le développeur qui reproduira la refonte dans le compte Wix de Beer My Guest. Base : le prototype local (prototype/). C’est une démonstration visuelle en HTML/CSS/JS, pas un template importable dans Wix. Chaque section porte une note de reconstruction : cliquez sur le bouton « Notes Wix » en bas à gauche de chaque page pour les afficher.

État des connaissances : 1er novembre 2026. Les fonctionnalités de Harmony évoluent vite, et l’aide Wix contient des listes « pas encore disponible » parfois contradictoires. Tout ce qui est marqué « à vérifier » doit être testé dans le compte avant de démarrer.

1.3 À vérifier dans le compte avant de commencer

  • Le CMS est-il activé sur ce compte ? C’est la décision structurante (voir § 3).
  • Les polices Cormorant Garamond et DM Sans sont-elles dans la bibliothèque Harmony ? L’import de polices est impossible (voir § 1.4).
  • Wix Events : personnalisation du widget de liste, page de détail, inscription et billets.
  • FAQ : l’application FAQ n’est pas documentée pour Harmony. Alternative : l’élément « Texte repliable » (Collapsible text).
  • Wix Gallery : les préréglages disponibles (grille, mosaïque/collage, survol).
  • Répéteurs : bouton « Charger plus » ou pagination (seul le réglage « Éléments par chargement » est documenté).
  • Filtre de répéteur : la condition « contient » sur un champ texte. Elle permettrait de classer une réalisation dans plusieurs catégories.
  • Redirections 301 (gestionnaire SEO) pour /gallerie et les anciennes URL de produits.
  • Avis Google : un widget compatible Harmony existe-t-il ?

2.3 Boutons

  • Principal : fond #24170F, texte crème, forme pilule (rayon maximal), hauteur environ 52 px. Survol : fond #5A3A26.
  • Accent (sur fond sombre) : fond #C27A1E, texte #24170F. Survol : #E9B661.
  • Secondaire : contour 1 px de la couleur du texte, fond transparent. Survol : inversion des couleurs.
  • Lien fléché : texte souligné suivi d’une flèche « → », sous forme de bouton texte.

2.4 Espacements et grilles

  • Largeur de contenu de 1 280 px, marges de 40 px (20 px sur mobile).
  • Espace vertical entre sections : environ 128 px sur ordinateur, 72 px sur mobile.
  • Grilles utilisées : 2 colonnes, 3 colonnes, 4 colonnes. Sur mobile, tout passe en 1 colonne, sauf les galeries (2 colonnes).

2.5 Animations (sobres et reproductibles)

  • Entrée « Fondu » (léger glissement vers le haut) sur les blocs de texte et les cartes, déclenchée une seule fois.
  • Effet souris : léger zoom des images au survol des cartes (à vérifier dans les effets de survol des images ; sinon, s’en passer).
  • En-tête fixe au défilement.
  • À éviter : parallaxe forte, animations en boucle, carrousels automatiques.

3.2 Si le CMS n’est pas disponible

  • Fiches de réalisation : créer une page modèle, puis dupliquer la page pour chaque réalisation et remplacer textes et photos. Simple pour la cliente jusqu’à 10 ou 12 réalisations environ.
  • Liste des réalisations : cartes statiques (image, textes, bouton) disposées en grille 2 colonnes, chaque bouton pointant vers sa page.
  • Ajouter une réalisation : dupliquer une fiche, dupliquer une carte, relier les deux. Prévoyez un court tutoriel vidéo pour la cliente.
  • Expériences : cartes statiques. Le bouton « En savoir plus » ouvre un popup (un popup par expérience) ou mène vers une page.

3.3 Reproduire les filtres de catégorie

Harmony n’a pas de filtres côté visiteur. Trois options, de la plus simple à la plus riche :

  1. Onglets (Tabs), recommandé :
    • un onglet « Toutes », puis un onglet par catégorie ;
    • chaque onglet contient un répéteur 2 colonnes avec un filtre fixe Catégorie = … ;
    • visuellement, c’est très proche du prototype.
  2. Une page par catégorie :
    • URL du type /nos-realisations/team-building ;
    • les « boutons filtres » sont de simples liens ;
    • meilleur pour le référencement, plus de pages à maintenir.
  3. Sans filtre : une seule grille triée par « Ordre ». Acceptable tant qu’il y a moins de 10 réalisations.
Une réalisation dans plusieurs catégories : le prototype le permet. Dans Harmony, ce n’est possible que si le filtre texte accepte « contient » (à vérifier). Sinon, n’attribuez qu’une seule catégorie par réalisation.

Même logique pour la page Expériences :

  • un onglet par public (Tous / Entreprises / Particuliers) ;
  • les filtres combinés public + format du prototype ne sont pas reproductibles sans code : ne gardez qu’un seul niveau d’onglets.

4.7 Expériences (catalogue)

  • Structure : en-tête, onglets par public, grille de 3 cartes ; fenêtre de détail au clic.

  • Wix Stores : sortir ces activités de Stores (elles ne sont pas vendues en ligne et s’affichent « Out of stock »). Garder Stores pour la carte cadeau et les produits réellement achetables.
  • Difficulté : ★★★

4.8 Agenda

  • Structure : en-tête, liste d’événements (date, titre, lieu, bouton Réserver), puis deux encarts de renvoi (Réalisations / Groupe privé).
  • Composants : application Wix Events (widget liste, page détail et inscription automatiques).
  • Contenus : les vraies dates, gérées par la cliente dans le tableau de bord Events. Les dates du prototype sont fictives.
  • À retenir : l’agenda présente les dates à venir ; les réalisations sont un portfolio du passé. Ne pas mélanger les deux.
  • Difficulté : ★★★ (mise en forme du widget à vérifier)

    • case de consentement RGPD.
  • Notifications : e-mail à contact@exemple.be et réponse automatique au visiteur.
  • FAQ : élément « Texte repliable », ou application FAQ si elle est disponible dans Harmony. Les réponses du prototype reprennent des informations du site, à valider par la cliente.
  • Compromis : le préremplissage du formulaire via l’URL (?experience=…) est une commodité du prototype, pas native dans Harmony. Le champ reste à remplir par le visiteur.
  • Difficulté : ★★

4.11 Journal (blog)

  • Structure : une seule page Blog (supprimer le doublon), flux en grille de 3 colonnes.
  • Règle : n’afficher le Journal dans le menu qu’à partir de 3 articles publiés ; sinon, le laisser en pied de page.
  • Difficulté : ★
