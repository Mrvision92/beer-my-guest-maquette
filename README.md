# Maquette de refonte — Beer My Guest

Maquette navigable d’une proposition de refonte, **à reconstruire dans Wix Harmony**. Ce n’est pas le site officiel de Beer My Guest : les coordonnées sont des exemples, les réalisations marquées « Exemple fictif » et les dates d’agenda sont des démonstrations.

- **Voir la maquette en ligne :** https://mrvision92.github.io/beer-my-guest-maquette/
- **Guide de reconstruction Wix Harmony :** page `dossier.html` (lien « Dossier projet » dans la maquette)
- **Astuce :** sur chaque page, le bouton « Notes Wix » (en bas à gauche) affiche les composants Wix à utiliser pour chaque section.

## Structure

| Fichier | Rôle |
|---|---|
| `index.html` | Sommaire de la maquette |
| `accueil.html`, `realisations.html`, `realisation.html`… | Pages de la maquette |
| `assets/css/style.css` | Design system (couleurs, typographies, composants) |
| `assets/js/data.js` | Contenus répétés : réalisations (futur CMS), expériences, événements |
| `assets/js/main.js` | En-tête, pied de page, filtres, fiches, lightbox, formulaire |
| `assets/img/` | Photos du site actuel, recadrées et compressées |

Site statique sans dépendance : ouvrir `index.html` dans un navigateur suffit.
