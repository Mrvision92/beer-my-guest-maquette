Carte cadeau

Vous souhaitez offrir un cadeau original ? Nos cartes cadeaux sont idéales ! La carte est valable sur tous nos produits sur le site ; les jeux de pistes sur Bruxelles, la journée bière, l’une de nos dégustations bière mensuelles affichées sur l’agenda… Que du bonheur !

Comment offrir une carte cadeau ?

Toutes les cartes cadeaux achetées sur le site sont valables sur l’ensemble du site ; le jeu de piste, la journée bière, les dégustations à l’agenda ou pour toute autre dégustation en groupe privé.

  1. Choisissez le montant de la carte cadeau.
  2. Possibilité d’ajouter un message personnalisé, simplement l’ajouter dans les commentaires lors de la confirmation d’achat ou possibilité de m’envoyer à contact@exemple.be.
  3. Vous recevrez la carte cadeau dématérialisée avec le code de réduction et les instructions.
  4. La carte cadeau est valable pendant 1 an à partir de la date d’achat.

Comment utiliser la carte cadeau ?

Toutes les cartes cadeaux achetées sur le site sont valables sur l’ensemble du site et pour toutes les activités.

  1. Munissez-vous de votre code de réduction.
  2. Choisissez l’activité de votre choix, « jeu de piste » ou « journée bière », qui vous correspond.
  3. Avant de payer, remplissez le champ code de réduction et validez le code promotion. Vous verrez alors le montant de la carte cadeau se déduire du prix total.
  4. Pour une dégustation privée ou activité faite sur mesure, veuillez nous envoyer le bon cadeau par mail à contact@exemple.be.

N’hésitez pas à nous contacter pour toute question, nous sommes tout ouïe !
